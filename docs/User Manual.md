# User manual

Choose a book, then use Previous and Next, the arrow keys, or a touch swipe to turn pages. Page turns follow the book's direction. Choose Continuous, One page, or Two pages in the reading bar or Preferences. Continuous mode scrolls into the next chapter. It shows the publisher's page label when available and a section label for books that reflow without one. You can hide the inline marks in Preferences.

The − and + buttons resize text in reflowable books and magnify fixed pages. Click the displayed zoom for presets and Reset. Fixed pages also offer Fit page and Fit width. With focus in the book, use +, −, or 0, or zoom with Ctrl + mouse wheel or a supported pinch gesture.

Choose a typeface, text size, spacing, margins, and alignment in Preferences. Use Reset to return to defaults or Export to save a copy you can Import on another device.

Pageglade saves your reading place as you go. Exit returns to the welcome screen in a browser and closes the desktop app. Reopen the same book or click Continue reading to return to your saved place.

The browser needs one successful online setup before it can reopen offline. When the welcome screen says Ready to read offline, the app has cached its files. Clearing browser site data removes the app's stored books and places. The web welcome screen and Help also have a Download desktop app chooser.
