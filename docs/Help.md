# Quick help

Open an EPUB with Open book, Ctrl or Command + O, or by dropping the file into the window.

Use Contents, Find, and Preferences from the toolbar. Ctrl or Command + K opens the command finder. Try “make text bigger.”

Use − and + in the reading bar to zoom. Open the zoom value for presets and Reset. With the book focused, press +, − or 0. You can also use Ctrl + mouse wheel or pinch where supported.

Choose Continuous in the reading bar to scroll across chapters. Turn start and end markers on or off in Preferences.

Focus hides reading tools and leaves Exit available. Press Escape or choose Leave focus to bring the tools back.
