# Changelog

## 0.5.0 development preview

- Continuous reading crosses section boundaries and displays page or section markers.
- Added zoom buttons, presets, keyboard shortcuts, wheel and pinch controls, and fixed-page fit modes.
- Added a desktop download chooser to the web welcome screen and Help.

## 0.1.0 development preview

### Added

- Local EPUB opening with contents, page controls, search, and reading preferences.
- Saved reading locations, an offline browser build, and a desktop development wrapper.
- Book-frame isolation, archive size limits, and clear errors for recognized protected books.
